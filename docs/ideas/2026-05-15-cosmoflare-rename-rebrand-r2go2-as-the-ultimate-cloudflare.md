# Cosmoflare — rename/rebrand R2Go2 as the ultimate Cloudflare CLI managing R2, Workers, KV, D1, DNS, Domains, Pages, Queues. R2Go2 becomes the R2 storage component within Cosmoflare.



**Cosmoflare** is a comprehensive, unified command-line tool that serves as a single point of management for your entire Cloudflare infrastructure—covering R2 storage, Workers, KV namespaces, D1 databases, DNS records, domains, Pages, and Queues. Rather than juggling multiple tools or the web dashboard, developers get a fast, scriptable CLI for everything. Under the hood, the existing **R2Go2** project becomes the dedicated R2 storage module within this larger ecosystem, preserving its functionality while expanding into a full-suite Cloudflare management tool.

**Why it's useful:** Instead of context-switching between `wrangler`, custom scripts, and the Cloudflare dashboard, Cosmoflare gives you one consistent interface. It's especially powerful for CI/CD pipelines, infrastructure-as-code workflows, and developers who live in the terminal.
