# D1 Depth — Implementation Plan

**Issue:** FEAT-022 | **Roadmap:** ROAD-091
**Brainstorm:** `docs/brainstorming/2026-09-11-d1-depth.md`

## Goal

Add migrations, time-travel restore, export, and import to cosmoflare's D1
surface. Each verb gets a library method on `D1Service` and a cobra CLI
command under `d1Cmd`. All commands support `--json`, `--local`/`--remote`,
and destructive verbs require confirmation.

## Phasing

Three agent dispatches, each bounded in scope.

---

### Wave 1 — Migrations (P-01, P-05 partial)

**Scope:** Library methods + CLI commands for `d1 migrations create`,
`d1 migrations list`, `d1 migrations apply`.

#### Library — `pkg/cosmoflare/d1.go`

Add these methods to `D1Service`:

1. **`MigrationsCreate(name string, migrationsDir string) (string, error)`**
   - Creates file `migrations/NNNN_<name>.sql` in `migrationsDir`.
   - Scans existing files to determine next sequence number.
   - Returns the created file path.
   - No API call (local filesystem only).

2. **`MigrationsList(ctx context.Context, databaseID string, migrationsDir string) ([]D1Migration, error)`**
   - Scans `migrationsDir` for `*.sql` files matching `NNNN_*.sql` pattern.
   - Queries the D1 database for applied migrations:
     ```sql
     SELECT name, applied_at FROM d1_migrations ORDER BY id
     ```
   - Returns a list of `D1Migration` structs with `Name`, `AppliedAt`
     (nil if pending), and `FilePath`.
   - Creates `d1_migrations` table if it does not exist (idempotent).

3. **`MigrationsApply(ctx context.Context, databaseID string, migrationsDir string, dryRun bool) ([]D1MigrationResult, error)`**
   - Calls `MigrationsList` to find pending migrations.
   - For each pending migration (in order):
     a. Read the SQL file.
     b. If `dryRun`: add to results as "would apply", skip execution.
     c. Execute the SQL via `Query()`.
     d. Record the migration in `d1_migrations`:
        ```sql
        INSERT INTO d1_migrations (name, applied_at) VALUES (?, ?)
        ```
     e. Add to results as "applied".
   - Returns list of `D1MigrationResult` (name, status, error if any).
   - Idempotent: already-applied migrations are skipped.

Add these types to `pkg/cosmoflare/d1.go`:

```go
type D1Migration struct {
    Name      string     `json:"name"`
    AppliedAt *time.Time `json:"applied_at"`
    FilePath  string     `json:"file_path"`
}

type D1MigrationResult struct {
    Name   string `json:"name"`
    Status string `json:"status"` // "applied", "skipped", "would_apply", "failed"
    Error  string `json:"error,omitempty"`
}
```

#### CLI — `cmd/d1_migrations.go` (new file)

Register under `d1Cmd`:

```text
cosmoflare d1 migrations create <database> <migration-name>
cosmoflare d1 migrations list <database> [--local|--remote]
cosmoflare d1 migrations apply <database> [--local|--remote] [--dry-run] [--force]
```

- `d1MigrationsCmd` — parent command with `Use: "migrations"`.
- `d1MigrationsCreateCmd` — `Args: cobra.ExactArgs(2)`, calls
  `svc.MigrationsCreate()`.
- `d1MigrationsListCmd` — `Args: cobra.ExactArgs(1)`, calls
  `svc.MigrationsList()`, prints table (NAME | STATUS | APPLIED AT).
- `d1MigrationsApplyCmd` — `Args: cobra.ExactArgs(1)`, calls
  `svc.MigrationsApply()`. When `--remote` and not `--force`: prompt user
  to type the database name. Scan pending migrations for destructive SQL
  (DROP, DELETE without WHERE, TRUNCATE) and print warnings.

**Flags:** `--migrations-dir` (default `migrations/`), `--local`,
`--remote` (default remote), `--dry-run`, `--force`, `--json`.

#### Tests — `pkg/cosmoflare/d1_migrations_test.go` (new file)

- `TestMigrationsCreate` — creates a file, verifies naming and sequence.
- `TestMigrationsCreate_NextSequence` — existing files, verifies next number.
- `TestMigrationsList_Empty` — no migrations dir, returns empty.
- `TestMigrationsApply_DryRun` — verifies no SQL is executed.
- `TestMigrationsApply_Idempotent` — apply twice, second is no-op.
- `TestDestructiveSQLDetection` — detects DROP TABLE, DELETE without WHERE.

### Wave 2 — Time-Travel Restore + Export (P-02, P-03, P-05 partial)

**Scope:** Library methods + CLI commands for `d1 time-travel restore` and
`d1 export`.

#### Library — `pkg/cosmoflare/d1.go`

4. **`TimeTravelRestore(ctx context.Context, databaseID string, timestamp time.Time) (*D1TimeTravelResult, error)`**
   - Calls `POST /accounts/{account_id}/d1/database/{database_id}/time_travel`
     (or `/restore` — verify exact endpoint via cloudflare-go).
   - Payload: `{"timestamp": "<ISO8601>"}`.
   - Returns `D1TimeTravelResult` with restore details.
   - Quota tracking: updates `.cosmoflare-time-travel-cache.json` with
     the restore timestamp. The cache stores `{databaseID: [{timestamp, restoredAt}]}`
     entries within the current 10-minute window.

5. **`TimeTravelQuotaCheck(databaseID string) (*D1TimeTravelQuota, error)`**
   - Reads `.cosmoflare-time-travel-cache.json`.
   - Counts restores for `databaseID` in the current 10-minute window.
   - Returns `D1TimeTravelQuota` with `Used`, `Limit` (10), `WindowResetsAt`.

6. **`Export(ctx context.Context, databaseID string) (io.ReadCloser, error)`**
   - Calls the D1 export endpoint.
   - Returns a reader for streaming the SQL dump.
   - The caller writes to stdout or a file.

Add these types:

```go
type D1TimeTravelResult struct {
    DatabaseID string    `json:"database_id"`
    Timestamp  time.Time `json:"timestamp"`
    Success    bool      `json:"success"`
}

type D1TimeTravelQuota struct {
    Used          int       `json:"used"`
    Limit         int       `json:"limit"`
    WindowResetsAt time.Time `json:"window_resets_at"`
}
```

#### CLI — `cmd/d1_timetravel.go` (new file)

```text
cosmoflare d1 time-travel restore <database> --timestamp <ISO8601> [--dry-run] [--force]
```

- Before restore: call `TimeTravelQuotaCheck()`. If used >= 10, print
  error with window reset time and exit.
- Default: interactive confirmation prompt (database name, ID, target
  timestamp). `--force` skips.
- `--dry-run`: print what would happen, don't call API.
- After restore: print remaining restores in the current window.
- `--json` output includes quota info.

#### CLI — `cmd/d1_export.go` (new file)

```text
cosmoflare d1 export <database> [--output file.sql] [--local|--remote]
```

- Default: streams SQL dump to stdout.
- `--output`: writes to file, prints progress (bytes written).
- `--local`: exports local SQLite D1 database.
- `--remote` (default): exports via Cloudflare API.
- `--json`: prints metadata (database name, size, output path) instead of
  the SQL dump itself.

#### Tests

- `pkg/cosmoflare/d1_timetravel_test.go` — quota tracking, window reset,
  cache file read/write.
- `cmd/d1_export_test.go` or `pkg/cosmoflare/d1_export_test.go` — export
  to file, stdout.

**Files touched:**
- `pkg/cosmoflare/d1.go` — add time-travel and export types and methods
- `cmd/d1_timetravel.go` — new file
- `cmd/d1_export.go` — new file

### Wave 3 — Import (P-04, P-05 partial)

**Scope:** Library methods + CLI for `d1 import`.

#### Library — `pkg/cosmoflare/d1.go`

7. **`Import(ctx context.Context, databaseID string, reader io.Reader, opts ImportOptions) (*D1ImportResult, error)`**
   - Reads SQL from the reader.
   - Splits into statements using the statement-aware splitter (see below).
   - Batches statements into ~40KB chunks.
   - Executes each batch via `Query()`.
   - On SQLITE_TOOBIG: splits the failing batch and retries individual
     statements.
   - On error 7500: retries with exponential backoff.
   - Reports progress (statements executed, bytes processed).
   - Returns `D1ImportResult` with totals.

8. **`SplitSQLStatements(sql string) []string`** (exported for FEAT-018 reuse)
   - Quote-aware: respects single quotes, double quotes, backticks.
   - Comment-aware: skips `--` line comments and `/* */` block comments.
   - Semicolon-delimited: splits on `;` outside quotes/comments.
   - Trims whitespace, skips empty statements.

Add these types:

```go
type ImportOptions struct {
    BatchSizeBytes int  // default 40960
    Concurrency    int  // default 1
    DryRun         bool
}

type D1ImportResult struct {
    StatementsExecuted int     `json:"statements_executed"`
    BatchesExecuted    int     `json:"batches_executed"`
    BytesProcessed     int64   `json:"bytes_processed"`
    RowsWritten        int     `json:"rows_written"`
    Duration           float64 `json:"duration_ms"`
    Errors             []string `json:"errors,omitempty"`
}
```

#### CLI — `cmd/d1_import.go` (new file)

```text
cosmoflare d1 import <database> --file <file.sql> [--local|--remote] [--dry-run] [--force] [--batch-size 40960]
```

- When `--remote` and not `--force`: prompt to type database name.
- `--dry-run`: parse the file, report statement count and estimated
  batches, don't execute.
- Progress output: `[batch 12/47] 1,234 statements | 480KB processed`.
- `--json` output: `D1ImportResult`.

#### Tests — `pkg/cosmoflare/d1_import_test.go` (new file)

- `TestSplitSQLStatements_Basic` — simple semicolon split.
- `TestSplitSQLStatements_QuotedSemicolons` — semicolons inside strings.
- `TestSplitSQLStatements_Comments` — line and block comments.
- `TestSplitSQLStatements_MultilineInsert` — multi-value INSERT.
- `TestImport_DryRun` — verifies no SQL executed.
- `TestImport_BatchSizing` — verifies batch byte limits.
