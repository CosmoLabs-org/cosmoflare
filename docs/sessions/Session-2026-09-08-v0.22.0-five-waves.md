# Session 2026-09-08 — v0.22.0: Five Waves, R2 Complete, Alerting Loop Live

**Prompt**: docs/prompts/2026-09-07-launch-and-hardening.md (carried into 2026-09-08-post-v0.22.0-control-plane.md)
**Branch**: master · **Result**: v0.22.0 released; R2 surface complete; observability loop live end-to-end

## Summary

The session ran as five waves with nine agent merges, every one S334-gated (diff read, tests
re-run in the worktree, artifacts stripped, ancestry check). Wave 1 fixed sync correctness
(multipart ETag fallback to size/mtime, remote mtime restored after download) and swept 6,311
lines of pre-rename dead code after a port review — the analytics draft turned out to be mock
data, the migration was strictly superseded, and exactly one real gap (R2 lifecycle policies)
was found and noted. Wave 2 delivered R2 bucket custom domains over raw REST, because
cloudflare-go v0.116 wraps nothing there and the /v7 generated client would force a
library-wide migration. Wave 3 lit up the observability loop end-to-end: GraphQL Analytics
producers for zones/R2/Workers, daemon partial snapshots with per-source errors, and the alert
evaluator firing `TriggerAlert` through the serve bridge to SSE. Wave 4 completed the R2
surface with lifecycle rules and event notifications, both built from spec-verified API facts
delivered by research agents. Then v0.22.0 shipped — 6 assets plus checksums, published Latest —
and a post-release simplify pass collapsed four review angles into a shared `restClient`
transport (−370/+241), `ux.Confirm`, library zone resolution, and metrics concurrency fixes.
