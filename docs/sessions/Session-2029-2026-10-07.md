- Pager v1 is a static PWA at cosmolabs.org/pager; desktop gains ack/snooze parity instead of new views; live-status/actions deferred to v2 gated on FEAT-029 device-flow auth.
- FEAT-046 restraint rule: one signature shader moment per surface — product-page hero yes, desktop ambient layer never (battery + WebGPU-in-WKWebView risk).
- v0.32.0 tag moved post-publish (delete-then-push) to a76932c after the proxy zip rejection — zero-install window made it safe; release assets were never affected.
- PRODUCT-VISION principle 6 pivoted: open-source core AND open-source pager; paid tiers are desktop depth + managed conveniences (5c058e8).


## Lessons Learned

- Observed: 4 of 10 GLM agents died with API 403 quota errors mid-task. Cause: dispatching waves near the quota window edge. Next: check the window before exec-batch; salvage --auto recovered 3 of 4 (one needed in-session completion) — keep salvage-first.
- Observed: proxy.golang.org rejected the v0.32.0 module zip over a COLON in a tracked filename (+04:00 timestamp in a feedback digest). Cause: the Makefile tree-path gate (BUG-052) scans non-ASCII but not colons. Next: extend the gate to reject ':' in tracked paths before any release (feedback filed).
- Observed: parallel same-package agent branches do not compile alone. Cause: worktrees fork from master without sibling work. Next: rebase each branch onto master before its gate (worked cleanly for 0317/0318/0319/0323/0324).
- Observed: S334 gates caught two real defects agents' prose never mentioned (slice-underflow, missing registry entries). Cause: salvaged/dead agents' self-reports are unreliable. Next: unchanged — fresh in-worktree tests are non-negotiable.
