Continuation session that started as a three-goal launch checklist and became a release-plus-feature wave. ## Lessons Learned

- Observed: 'Google-side latency' theory for pkg.go.dev was wrong. Cause: git quotes non-ASCII paths octal-escaped, so plain grep '❓' on ls-tree/log output returns false-clean — scans must use -c core.quotepath=off. Next: any tree-audit gate must set quotepath=off + LC_ALL=C.
- Observed: 3/11 GLM-5.3-flash dispatches stalled with zero file activity. Cause: 2m idle default too short for read-heavy test-writing tasks. Next: dispatch test-authoring tasks with --idle-timeout 10m from the start.
- Observed: inline exec task strings truncate silently (task_truncated visible only in status JSON). Cause: long bash-quoted arguments. Next: use --prompt files for any multi-sentence brief.
- Observed: agent prose said 'done' while commits were wip(salvage) auto-commits. Cause: agents die at wrap-up after writing files. Next: trust the diff + own test run, never the status label — S334 held every time.
- Observed: make -n on credential-guarded recipes expands live env secrets into its echo. Cause: make prints recipes with env expansion under -n. Next: avoid make -n on guarded targets with real credentials exported.
