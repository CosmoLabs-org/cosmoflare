## Key Decisions

- Shared JSON contracts in one plan doc before dispatch so 5 agents could build Worker and UI in parallel (ff53903).
- KV is the shared L2 cache because Cloudflare docs say the Cache API is unavailable behind Access (a43bb75).
- Billing cycle anchored on day 23 from the operator's dashboard because the token lacks Billing Read; the subscription API returns 10000 (BUG-056, 67350ca).
- No left-border accents or tile outlines; impeccable detector must stay at 0 (operator rule, 96f3d06).
- Over-limit gauges are red with a flowing stripe and glow; reduced motion disables it (operator request, 8928ebf).
- Integration defects found at session end are filed, not fixed, per operator (BUG-p87APZK, BUG-pQV6P4X).


## Lessons Learned

- Observed: every Ops view failed in production while localhost looked fine. Cause: the client fell back to fixtures and fetch was stored as this.fetchFn. Next: verify pager changes on live data via the scratchpad api-server + Playwright.
- Observed: agents claimed GraphQL fields were not exposed. Cause: incomplete probing. Next: re-check every 'not available' claim by introspection.
- Observed: flash agents died at 120-150 turns on large briefs. Cause: scope too big for the flash tier. Next: bounded briefs, continue with --base-branch.
- Observed: parallel agents appending to one CSS file produced a conflict that dropped a closing brace. Next: assign one CSS owner per wave or re-check brace balance after merging.
