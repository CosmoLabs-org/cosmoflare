## Lessons Learned

- Observed: Three merges showed scary 'deletion' diffs that were pre-merge-base artifacts (branch predates a master merge) — Cause: Two-dot diff master..HEAD against a moved master; three-way merge preserves everything — Next: On any deletion-heavy agent diff, check merge-base before assuming revert; ancestry-check the post-BUG-597-strip tip, not the branch tip
- Observed: Export pipelines mangle machine JSON (escaped brackets, image-placeholder formulas) — Cause: Gemini/Docs export formatting, not data loss — Next: Tolerant-parse with json.JSONDecoder().raw_decode from the first '[' — recovered 52/52 pricing and 7/7 coverage entries; re-fetch Vectorize formulas from source before cost math
- Observed: Test side-effect files (.cosmoflare-d1-import-progress.json) blocked two merges — Cause: Untracked artifacts regenerated by test runs in worktrees — Next: Gitignored at source; apply the same check to any new stateful feature
- Observed: Agent briefs with 'read X and follow patterns' trigger validation warnings but succeed when endpoints+signatures stay pinned — Cause: Discovery-language detector is advisory; the pinning is what keeps tasks bounded — Next: Keep pinning exact endpoints/types in briefs; treat the warning as noise unless scope actually grew
