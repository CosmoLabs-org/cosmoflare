## Lessons Learned

- GLM agents die at idle timeouts mid-test but auto-salvage preserves complete work — salvage-then-verify beats redispatch.
- Test helpers must ZERO credential globals, not just snapshot: a prior suite test leaving AccountID set flips offline tests to dry-run-success (two agents hit this).
- Cobra merges inherited persistent flags after any root Execute — own-flag assertions need LocalFlags() or they are order-dependent.
- Register funcs that add flags must be idempotent (Lookup guard); package-level command vars get registered twice otherwise.
- ccs merge blocks on .verify/.review.json gate artifacts — commit them inside the worktree first.
