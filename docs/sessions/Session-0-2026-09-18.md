## Lessons Learned

- Agent-authored test suites reliably break in the same three ways when they time out mid-flight: self-recursive helpers, unbalanced parens around handler literals, and assigned-but-unused servers — check those three first when salvaging
- Order-dependent cmd tests trace to rootCmd writer pollution (SetOut to a private buffer, never restored) — hermetic tests must snapshot AND rebind writers inside the captured scope
- A test asserting documented-but-unbuilt behavior (disabled alert rules) found a real library gap — when the test and code disagree, check which one states the intended contract
- Coverage work found a production crash no feature test caught: zero-value option fields reaching io.CopyBuffer — zero-value defaults deserve explicit boundary tests in option-consuming code
- Monitor scripts must match the real agent-id allocation (batch 005 ran as 0269-0278, not the 0266-0275 the monitor watched) — derive ids from exec-batch output, never assume contiguous ranges
