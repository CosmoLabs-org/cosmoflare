Cosmoflare

The whole Cloudflare platform in one Go binary.

Open-source CLI and library for R2, DNS, Zones, SSL/TLS, Cache, WAF, D1, KV, Queues, Pages, Images, Stream and 10+ more services. No Node.js. --json on every command. A built-in MCP server that is read-only until you say otherwise.

go install github.com/CosmoLabs-org/cosmoflare@latest
brew install CosmoLabs-org/cosmoflare/cosmoflare

Why Cosmoflare

  • Full platform, one binary. 22 Cloudflare services from a single ~37 MB static executable — zero runtime dependencies.
  • Scriptable by design. JSON output with one envelope shape and deterministic exit codes on every command.
  • Agent-safe. The built-in MCP server exposes 140+ tools, read-only by default; mutations need an explicit allow switch, and uploads can be capped by bucket allowlist, key patterns and size limits.
  • Actionable errors. An embedded knowledge layer decodes Cloudflare API errors into causes and fixes.
  • Migrates both ways. Import your wrangler.toml; export Terraform for the road to IaC.
  • A library underneath. pkg/cosmoflare is a stable public Go API — the CLI, the MCP server and our desktop app all wrap it.

Quick start

export CLOUDFLARE_API_TOKEN="your-token"
export CLOUDFLARE_ACCOUNT_ID="your-account-id"

cosmoflare zone list --json
cosmoflare dns create ZONE_ID --type A --name app --content 1.2.3.4
cosmoflare object put my-bucket ./file.txt --key uploads/file.txt
cosmoflare object presign my-bucket uploads/file.txt --expires 1h
