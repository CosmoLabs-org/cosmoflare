## Context

FEAT-022 adds four capabilities to the D1 command surface: migrations
(create/list/apply with wrangler-compatible `d1_migrations` table),
time-travel restore (with 10/10min hard quota pre-flight), export (streaming
SQL dump), and import (statement-aware splitter reusing FEAT-018 design).

The plan is phased into 3 waves for bounded agent dispatch:
- **Wave 1:** Migrations (P-01) — library methods + CLI + tests
- **Wave 2:** Time-travel restore + Export (P-02, P-03) — library + CLI + tests
- **Wave 3:** Import (P-04) — library + SQL splitter + CLI + tests

Every new verb supports `--local`/`--remote`, `--json`, and destructive
verbs require confirmation (bypassed by `--force`). Existing patterns in
`cmd/d1.go` and `pkg/cosmoflare/d1.go` are the template.

**Key references:** The D1 mapping corpus has exact API endpoints. The D1
security corpus (sections 6-7) prescribes confirmation prompts, dry-run
discipline, and destructive SQL detection. Import shares the splitter design
with FEAT-018 `d1 push-sql` (reference, not duplicate).
